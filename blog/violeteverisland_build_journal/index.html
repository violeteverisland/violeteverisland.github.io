网站搭建记录

搭建记录

violeteverisland 搭建记录（Astro + 樱花主题 + Live2D + Nginx）

项目目标

搭建一个：

  • 二次元浓度高的个人博客
  • 樱花主题、简洁、令人愉悦
  • 带 Live2D 看板娘
  • 使用 Astro 作为框架
  • Nginx 部署
  • 开发环境与生产环境分离

一、技术路线选择

最终采用：

前端框架：Astro
样式：Tailwind（最终回退 v3 稳定方案）
博客内容：Markdown
Live2D：pixi.js + pixi-live2d-display
部署：Nginx 静态托管 dist
开发：npm run dev

放弃过的路线：

  • Astro SSR + 外部 Markdown 实时读取（过重，体感更卡）
  • 线上直接跑 dev server（调试方便，但不适合作为最终线上方案）

最终结论：

开发用 dev
上线用静态 build

二、项目初始化

创建项目：

npm create astro@latest

安装依赖：

npm install

启动开发：

npm run dev

三、博客结构（Content Collections）

目录结构：

src/
 ├─ content/
 │   └─ blog/
 │       └─ hello-world.md
 │
 ├─ pages/
 │   └─ blog/
 │      ├─ index.astro
 │      └─ [slug].astro
 │
 └─ layouts/
     └─ SakuraLayout.astro

注意：

不是 post，而是 blog。

动态路由：

src/pages/blog/[slug].astro

否则会出现：

Missing parameter: slug

以及：

404 /blog/hello-world/

四、Content Schema 踩坑

文章 frontmatter 必须包含：

---
title: Hello World
description: 我的第一篇博客
pubDate: 2026-04-24
---

缺 description 会报：

InvalidContentEntryDataError

五、樱花主题设计

主题关键词：

  • Sakura Pink
  • 轻量卡片风
  • 柔和留白
  • 日系博客氛围

统一布局：

src/layouts/SakuraLayout.astro

网站标题改成：

<title>violeteverisland</title>

标签页标题固定：

violeteverisland

六、Live2D 看板娘

使用模型

模型：

HCw_Cyrene.model3.json

放在：

public/live2d/model/

安装依赖

最终稳定组合：

npm install pixi.js@6 pixi-live2d-display

（不要用 Pixi 7/8，会有 transform / interaction 冲突）

Cubism Runtime

布局 head 中：

<script
is:inline
src="https://cubism.live2d.com/sdk-web/cubismcore/live2dcubismcore.min.js">
</script>

踩过的坑

1.

Could not find Cubism 2 runtime

原因：错误用了 Cubism2 路径。

改成：

import { Live2DModel } from "pixi-live2d-display/cubism4"

2.

updateLocalTransform is not a function

原因：Pixi 版本不匹配。

解决：

pixi.js@6

3.

Outdated Optimize Dep

解决：

rm -rf node_modules/.vite .astro
npm run dev -- --force

延迟加载优化

改成后加载，减轻首屏压力。

ClientRouter 持久化

尝试过：

<ClientRouter />
transition:persist

结论：复杂度高，收益有限，放弃。

七、部署（最终方案）

构建

npm run build

Nginx

server {
    listen 127.0.0.1:54321;
    server_name localhost;

    root /home/jy/myblog/sakura-blog/dist;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;
    }
}

检查：

sudo nginx -t
sudo systemctl reload nginx

八、开发环境

服务器开发：

npm run dev -- --host 127.0.0.1 --port 4321

域名白名单：

vite: {
  server: {
    allowedHosts: [
      'www.violeteverisland.space',
      'violeteverisland.space'
    ]
  }
}

否则会报：

Blocked request. This host is not allowed.

九、Tailwind 大坑与修复

曾使用：

@tailwindcss/vite
Tailwind v4

构建炸：

Missing field tsconfigPaths

最终回退：

卸载

npm uninstall @tailwindcss/vite tailwindcss

安装 v3

npm install -D tailwindcss@3.4.17 postcss autoprefixer

global.css

@tailwind base;
@tailwind components;
@tailwind utilities;

不再用：

@import "tailwindcss";

tailwind.config.cjs

module.exports = {
content:[
'./src/**/*.{astro,js,ts,md,mdx}'
],
theme:{extend:{}},
plugins:[]
}

十、最终工作流

写文章

编辑：

src/content/blog/*.md

然后：

./deploy.sh

deploy.sh

#!/bin/bash
set -e

cd /home/jy/myblog/sakura-blog

git pull
npm install
npm run build

sudo nginx -t
sudo systemctl reload nginx

十二、经验总结

这次踩坑主要有三类：

Astro 路由坑

  • post/blog 路径混乱
  • slug 参数问题
  • 动态路由 404

Live2D 生态坑

  • Cubism runtime
  • Pixi 版本兼容
  • Vite optimize 缓存

Tailwind 新生态坑

  • v4 插件不稳定
  • 回退 v3 最稳

最终架构：

本地开发：npm run dev
线上部署：静态 dist + nginx
内容管理：Markdown
视觉增强：Live2D

这套是目前最平衡的一版。
